09In practice

Pilot. Project. Enable. Retrain.

One line of configuration per column.

  1. 01PilotRun the profiler on a sample of the target data.
  2. 02ProjectEstimate the overhead with T(n, m, k) before committing.
  3. 03EnableTurn on learned checks only for columns where they work.
  4. 04RetrainSchedule retraining as a recurring Airflow task.

profiling_schema.yml

Rules and learned checks, declared together
training:
  n_trials: 25

columns:
  surface_pressure:
    type: float
    automl: true       # learned check on
    checks:
      not_null: true
      range: [870, 1085]

  precipitation:
    type: float
    automl: false      # rule checks only
    checks:
      not_null: true
      range: [0, 300]
10Scope

What remains open.

The evidence holds for the setting tested here.

Point shifts, not drift

Anomalies were injected point shifts. Sustained drift is untested.

One column at a time

Shifts that only appear across several columns together are not detected.

Seasonal domains

Finance, IoT streams and abrupt regime changes remain to be evaluated.

Rules define what is allowed.Learning defines what is normal.

Reliable data needs both.
